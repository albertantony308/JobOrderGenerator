## 🚀 About

**Job Order Generator** (JobOrgan) is a desktop application designed for marine and vessel service operations. It streamlines the creation, management, and tracking of service memos and job orders for fleet maintenance teams.

### Key Features

- 📋 **Service Memo Management** — Create and manage service memos with full detail tracking
- 🔍 **Smart Search & Filter** — Quickly locate jobs by vessel, date, status, or technician
- 🖨️ **Print-Ready Reports** — Generate professional formatted job order printouts
- 🔄 **Auto-Update** — Seamlessly receive new versions without manual reinstall
- 🔐 **License-Based Access** — Secure, per-installation licensing system
- 🌙 **Modern Dark UI** — Premium desktop experience with theming support

## 📦 Installation

1. Download the installer from [Releases](https://github.com/albertantony308/JobOrderGenerator/releases/latest)
2. Run `JobOrderGenerator_Setup_vX.X.X.exe` as Administrator
3. Follow the installation wizard
4. Launch **Job Order Generator** from the Start Menu or Desktop shortcut
5. Enter your license key when prompted on first launch
